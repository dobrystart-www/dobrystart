# Dobry Start — strona demonstracyjna

Prosta, responsywna strona firmowa w jednym pliku HTML. Nie wymaga instalowania bibliotek.

## Przed publikacją
1. Otwórz `index.html`.
2. Zmień nazwę „Dobry Start” na swoją nazwę marki.
3. Zmień przykładowe ceny i opisy zgodnie z faktyczną ofertą.
4. Zmień `kontakt@twojafirma.pl` na swój prawdziwy adres e-mail.
5. Sprawdź wszystkie teksty, linki i wygląd na telefonie.

## Publikacja przez GitHub + Vercel
1. Utwórz repozytorium na GitHubie.
2. Prześlij `index.html` do głównego katalogu repozytorium.
3. W Vercel wybierz **Add New → Project** i zaimportuj repozytorium.
4. Dla zwykłej strony HTML nie trzeba ustawiać komendy budowania; jeśli Vercel pyta o framework, wybierz **Other**.
5. Wdróż projekt i otwórz adres przyciskiem **Visit**.

## Ważne
- Formularz kontaktowy nie jest skonfigurowany — przycisk otwiera program pocztowy przez `mailto:`.
- Nazwa marki, ceny i adres e-mail są przykładowe. Uzupełnij je przed pokazaniem strony klientom.
- Jeśli Vercel pokazuje 404, sprawdź, czy `index.html` znajduje się w katalogu głównym projektu i czy Root Directory wskazuje ten katalog.
